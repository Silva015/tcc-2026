Forensic examination of gunshot wounds must establish whether a wound is an entry or an exit wound and, for entry wounds, from what distance the shot was fired, questions that are hard even for experienced examiners when the signs are altered or incomplete. This work proposes TransferKAN, which combines a pre-trained convolutional network, ResNet-152, with a Kolmogorov-Arnold Network (KAN) as its classification layer, together with a multitask variant that solves both tasks with a single network, and evaluates them on real crime-scene photographs from the FDCPUnBGunshotDB database. As a starting point, the published tables for this database were reproduced; the reproduction showed that the train/test split behind them places photographs of the same case on both sides, which inflates mainly the shooting-distance results, so the KAN study was carried out with cross-validation grouped by case. With the feature extractor, the training and the number of parameters held fixed, the KAN head performed on par with the usual dense heads in the entry/exit task and slightly worse in the distance task, and replacing the KAN functions with wavelets did not change this picture. The multitask network produced both answers with about half the parameters and half the inference time, with no loss in shooting distance and a small loss in entry/exit, within the margin fixed before the experiments. Contact shots, with few examples in the database, remain the main limitation.
